# Full Stack E-Commerce Application

## Overview

A full-stack e-commerce application developed using Angular and Spring Boot. The application demonstrates frontend-backend integration, REST APIs, database operations, and responsive web design.

## Technologies

* Angular
* TypeScript
* Java
* Spring Boot
* REST APIs
* MySQL

## Features

* Product catalog
* Shopping cart
* RESTful services
* Database integration
* Responsive design

## Purpose

This project demonstrates modern full-stack development using Angular and Spring Boot technologies.

## Skills Demonstrated

* API Development
* Frontend Development
* Backend Development
* Database Integration
* Full-Stack Architecture
